## 研究 (Research)

- [Redesign Mixture-of-Experts Routers with Manifold Power Iteration](https://arxiv.org/abs/2606.12397) — 提出用流形幂迭代（Manifold Power Iteration）重新设计 MoE 路由机制，替代传统 Top-K 门控。在多个 MoE 模型上验证了路由效率和模型质量的提升。对做大模型架构优化的研究者有直接参考价值。 `HuggingFace` `↑ 73`

- [Toward Generalist Autonomous Research via Hypothesis-Tree Search](https://arxiv.org/abs/2606.11926) — 提出"假设树搜索"（Hypothesis-Tree Search）框架，让 AI 系统自主规划、执行和迭代科学研究流程。目标是实现通用科研 Agent。展示了在多个科学领域的实验结果。 `HuggingFace` `↑ 62`

- [Claw-SWE-Bench: A Benchmark for Evaluating OpenClaw-style Software Engineering Agents](https://arxiv.org/abs/2606.12344) — 一个专门评估 OpenClaw 风格软件工程 Agent 的基准测试。覆盖代码生成、调试、重构、部署等真实开发场景，为 Agent 能力评估提供了标准化工具。`HuggingFace` `↑ 55`

- [Agentic Environment Engineering for Large Language Models](https://arxiv.org/abs/2606.12191) — 研究 LLM Agent 如何自主设计和优化自身运行环境。Agent 可以修改提示模板、工具配置和执行策略来提升任务表现。对构建生产级 Agent 系统有实操启发。`HuggingFace` `↑ 55`

- [Beyond Scalar Rewards: Internalizing Reasoning into Scoring Models](https://arxiv.org/abs/2606.09076) — 提出超越标量奖励的 RL 方法：将推理过程内化到评分模型中，用结构化反馈替代单一数值奖励。在数学推理和代码生成任务上验证了有效性。`HuggingFace` `↑ 47`

- [Grammar-Constrained Decoding Can Jailbreak LLMs into Generating Structured Malicious Content](https://arxiv.org/abs/2606.11817) — 揭示一种新型越狱方法：通过语法约束解码（grammar-constrained decoding）诱导 LLM 生成结构化的恶意内容（如漏洞利用代码、钓鱼邮件模板）。指出当前安全对齐在结构化输出场景下存在盲区。`HuggingFace` `↑ 16`

- [TRACE: A Unified Rollout Budget Allocation Framework for Test-Time Compute](https://arxiv.org/abs/2606.11119) — 提出统一框架 TRACE，用于在测试时动态分配推理计算预算。解决"何时该让模型多想一会"的资源配置问题，在推理效率和准确率之间找到更好的平衡点。`HuggingFace` `↑ 14`

- [ICA Lens: Interpreting Language Models Without Training Auxiliary Models](https://arxiv.org/abs/2606.11722) — 提出 ICA Lens 方法，无需训练辅助模型即可直接解释 LLM 内部表征。相比现有可解释性方法更轻量、更高效。对做 LLM 可解释性和安全审计的研究者有用。`HuggingFace` `↑ 14`
