## 今日精选

### 1. [Gemma 4 12B: A unified, encoder-free multimodal model](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemma-4-12b/)
**来源**: HackerNews · score 500+
**中文摘要**：Google 发布 Gemma 4 12B，Apache 2.0 开源协议，最大的技术亮点是采用无编码器（encoder-free）架构——不依赖独立的视觉或音频塔，而是通过轻量级嵌入模块直接将图像和音频投影到文本 token 空间。这意味着一个统一的 LLM 主干即可处理多模态输入，大幅简化部署。
**为什么值得看**：这是开源本地多模态模型的一次架构级突破。对关注本地部署、端侧 AI 的开发者来说，这种"一个模型搞定所有模态"的设计思路值得深入了解一下。

### 2. [headroom — Compress tool outputs, logs, files, and RAG chunks before they reach the LLM](https://github.com/chopratejas/headroom)
**来源**: GitHub Trending · ⭐ 1000+ today
**中文摘要**：一个专门做 LLM 上下文压缩的工具——在工具输出、日志、文件、RAG 检索块进入 LLM 上下文窗口之前，先进行智能压缩。解决的核心痛点是：agent 执行过程中产生的中间结果越来越多，上下文窗口被快速填满，导致成本飙升和性能下降。
**为什么值得看**：随着 agent 工作流越来越复杂、执行步数越来越多，上下文压缩正从锦上添花变成刚需。这个工具的设计思路直接对应"token 预算管理"这个现实问题。

## 研究 (Research)

- [Streaming Communication in Multi-Agent Reasoning](https://arxiv.org/abs/2606.05158) — 多 agent 推理场景下，流式通信机制如何提升协作效率。提出了让 agent 在推理过程中持续交换部分结果而非等完整输出后再通信的方案。 `HuggingFace Top` `↑ 42`

- [Toward Pre-Deployment Assurance for Enterprise AI Agents: Ontology-Grounded Simulation and Trust Certification](https://arxiv.org/abs/2606.04037) — 面向企业级 AI agent 的部署前安全认证框架：用本体论驱动的仿真环境来验证 agent 行为是否合规，再输出可信认证报告。适合关注 agent 安全审计的团队。 `arXiv`

- [RUBAS: Rubric-Based Reinforcement Learning for Agent Safety](https://arxiv.org/abs/2606.04051) — 用评分准则（rubric）替代传统 reward model 来做 RL 安全对齐。核心思路：把安全要求拆成多个可打分维度，让 agent 在 RL 训练中学会在多个约束下行动。 `arXiv`

- [Where Do Deep-Research Agents Go Wrong? Span-Level Error Analysis](https://arxiv.org/abs/2606.02060) — 对 deep-research 类型 agent 的细粒度错误分析：定位到 span 级别，找出 agent 到底在搜索、推理、还是整合阶段出错。实用价值高。 `HuggingFace Top` `↑ 58`

- [SaliMory: Orchestrating Cognitive Memory for Conversational Agents](https://arxiv.org/abs/2606.04120) — 为对话 agent 设计的认知记忆编排系统，模拟人脑"短期/长期记忆"的协作机制，让 agent 在长对话中更准确地检索和使用历史信息。 `arXiv`

- [State Space Models are Surprisingly Effective Tabular Models](https://arxiv.org/abs/2606.04122) — 发现状态空间模型（SSM/Mamba 类）在处理表格数据时出人意料地好用，可能成为结构化数据领域的新选择。 `arXiv`

- [How to Train Your DRAM: Deep RL Models for Memory Controller Optimization](https://arxiv.org/abs/2606.04255) — 用深度强化学习优化 DRAM 内存控制器，把 AI 训练方法反过来优化 AI 运行的硬件。跨领域交叉，视角独特。 `arXiv`

- [Language Model-Based Edge Caching: A Semantic-Aware Approach](https://arxiv.org/abs/2606.04193) — 用语言模型的语义理解能力优化边缘缓存策略，判断哪些内容值得缓存、缓存多久。对做 CDN/边缘计算的人有参考价值。 `arXiv`
