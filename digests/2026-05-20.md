- [OpenComputer: Verifiable Software Worlds for Computer-Use Agents](https://arxiv.org/abs/2605.19769) — 构建可验证的软件执行环境让 AI Agent 在真实电脑中完成任务，同时保证过程可审计和结果可复现，是 computer-use agent 安全性的重要基础设施。 `HuggingFace` `upvotes: 49`
- [GoLongRL: Capability-Oriented Long Context Reinforcement Learning for Web Agents](https://arxiv.org/abs/2605.19577) — 针对 Web Agent 的长上下文强化学习训练方法，让模型在浏览、填表、多页面导航等长程任务中保持稳定表现，解决了一般 RL 在长程任务中的信用分配难题。 `HuggingFace` `upvotes: 47`
- [CHI-Bench: Can AI Agents Automate End-to-End, Long-Horizon Computer Tasks?](https://arxiv.org/abs/2605.16679) — 首个评估 AI Agent 完成端到端、长周期计算机任务能力的 benchmark，涵盖从文件操作到软件测试的完整工作流，是对现有 Agent 评测的重要补充。 `HuggingFace` `upvotes: 43`
- [EnvFactory: Scaling Tool-Use Agents via Executable Environment Generation](https://arxiv.org/abs/2605.18703) — 通过自动生成可执行环境来规模化训练工具调用 Agent，解决了工具学习数据稀缺的瓶颈，是训练数据工程方向的重要突破。 `HuggingFace` `upvotes: 38`
- [CogOmniControl: Reasoning-Driven Controllable Video Generation via Generative Models](https://arxiv.org/abs/2605.19995) — 支持通过自然语言指令对视频生成进行细粒度可控操作，在保持视频质量的同时实现了前所未有的控制精度，适合视频 AI 应用开发者关注。 `HuggingFace` `upvotes: 31`
- [Process Rewards with Learned Reliability](https://arxiv.org/abs/2605.15529) — 提出学习过程奖励可靠性的方法，解决 RL 中过程奖励模型不稳定的问题，在多个任务上显著提升了最终策略质量，对 RL 研究者和实践者都有参考价值。 `HuggingFace` `upvotes: 44`
