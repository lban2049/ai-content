## 研究 (Research)

- [LongLive-2.0: An NVFP4 Parallel Infrastructure for Long Video Understanding](https://arxiv.org/abs/2605.18739) — 在 Apple M3 Ultra 上系统性地验证了扩散模型在非 CUDA 平台（统一内存架构）上的优化路径与 CUDA 平台的差异，揭示了量化、Neural Engine 等技术在 Apple Silicon 上的独特行为，对在 Apple 硬件上部署 diffusion 模型有直接参考价值。 `HuggingFace` `upvotes: 85`
- [AgentWall: A Runtime Safety Layer for Local AI Agents](https://arxiv.org/abs/2605.16265) — 首个将 MCP 代理改造为运行时安全策略执行层的系统，在本地 Agent 执行前插入策略检查和人工审批环节，报告 92.9% 策略执行准确率和亚毫秒级开销，对关注 Agent 安全的团队有参考意义。 `arXiv` `new`
- [ANNEAL: Adapting LLM Agents via Governed Symbolic Patch Learning](https://arxiv.org/abs/2605.16309) — 将 LLM Agent 的反复失败转化为符号知识图谱的可控编辑，无需修改模型权重即可持久修复执行流程，是符号修复与神经方法的首次系统结合，在 27 个多种子场景中将反复失败率从 72-100% 降至 0%。 `arXiv` `new`
- [SkillsVote: Lifecycle Governance of Agent Skills](https://arxiv.org/abs/2605.18401) — 首个覆盖 Agent 技能从策展、版本治理到退役全生命周期的管理框架，解决了多 Agent 系统中技能策展混乱的问题。 `HuggingFace` `upvotes: 75`
- [Lance: Unified Multimodal Modeling by Multi-Task Synergy](https://arxiv.org/abs/2605.18678) — ByteDance 开源的多模态统一模型，支持图像、视频理解和生成，用 3B+3B+3B 三组件架构实现，是开源侧多模态统一的重要进展。 `HuggingFace` `upvotes: 59`
- [Auditing Agent Harness Safety](https://arxiv.org/abs/2605.14271) — 首个专门评估 Agent 测试框架安全性的 benchmark，对 Claude Code、OpenAI Agent SDK 等主流 harness 进行系统性安全审计。 `HuggingFace` `upvotes: 45`
- [Code-as-Room: Generating 3D Rooms from Top-Down View Images](https://arxiv.org/abs/2605.18451) — 将 2D 俯视图图像转换为 3D 房间布局的新方法，对室内设计自动化和 AI 场景生成有应用价值。 `HuggingFace` `upvotes: 34`
- [OProver: A Unified Framework for Agentic Formal Theorem Proving](https://arxiv.org/abs/2605.17283) — 在 LLM Agent 框架下统一形式化定理证明的系统，解决了 Agent 在高难度数学推理中的工具调用混乱问题。 `HuggingFace` `upvotes: 28`
