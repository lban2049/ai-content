## 研究 (Research)

- [JoyAI-VL-Interaction: Real-Time Vision-Language Interaction Dataset and Model](https://arxiv.org/abs/2606.14777) — 发布了一个大规模实时视觉-语言交互数据集和模型，聚焦于人机实时协作场景，支持视频流中的动态指令理解和响应。适合关注多模态 Agent 和实时 VL 方向的研究者。 `HF Top Papers` `↑ 153`

- [PhoneHarness: Harnessing Phone-Use Agents through Mixed GUI, CLI, and Tool Actions](https://arxiv.org/abs/2606.14832) — 提出一个手机操作 Agent 测试框架，支持 GUI、CLI 和工具调用三种交互模式的混合操作，在 Android 真实应用上评估 Agent 的跨模式能力。 `arXiv`

- [Trust Between AI Agents: Measuring Formation, Breakage, and Recovery](https://arxiv.org/abs/2606.14923) — 首次系统性地研究 AI Agent 之间的信任机制：如何建立、何时破裂、能否恢复。为多 Agent 协作系统的治理提供了可量化的评估框架。 `arXiv`

- [PrologMCP: A Standardized Prolog Tool Interface for LLM Agents](https://arxiv.org/abs/2606.14935) — 将 Prolog 逻辑编程通过 MCP 协议标准化接入 LLM Agent，实现符号推理与神经网络的互补。对关注 Agent 工具标准化和逻辑推理结合方向的开发者有参考价值。 `arXiv`

- [Remember, Don't Re-read: Stateful ReAct Agents for Token-Efficient Autonomous Experimentation](https://arxiv.org/abs/2606.14945) — 提出有状态 ReAct Agent 架构，通过记忆机制避免重复读取上下文，在科学实验自动化场景中显著降低 token 消耗。适合关注 Agent 效率优化和长时间自主运行的研究者。 `arXiv`

- [Are Online Skill and Memory Modules Always Worth Their Tokens?](https://arxiv.org/abs/2606.15017) — 对 Web Agent 的在线技能和记忆模块进行了预算约束下的成本效益分析，发现在很多场景下这些模块的 token 开销大于其带来的收益，提出了动态加载策略。 `arXiv`

- [OSGuard: A Benchmark for Safety in Computer-Use Agents](https://arxiv.org/abs/2606.15034) — 发布首个针对计算机操作 Agent 的安全基准测试，覆盖文件操作、网络访问、系统配置等 12 个风险维度。对评估和部署 GUI Agent 的团队来说是个重要的安全参考。 `arXiv`

- [Geometric Action Model for Robot Policy Learning](https://arxiv.org/abs/2606.17046) — 利用几何动作建模改进机器人策略学习，在复杂操作任务上展示了比传统方法更好的泛化能力。 `HF Top Papers` `↑ 80`
