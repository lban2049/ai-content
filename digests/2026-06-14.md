## 研究 (Research)

- [MiniMax Sparse Attention](https://huggingface.co/papers/2606.13392) — MiniMax 团队提出稀疏注意力机制，通过选择性计算显著降低长序列推理成本。对于需要处理超长上下文的场景（代码库分析、长文档理解）有直接应用价值。 `HuggingFace` `↑ 115`
- [SpatialClaw: Rethinking Action Interface for Agentic Spatial Reasoning](https://huggingface.co/papers/2606.13673) — 重新设计 Agent 在空间推理任务中的动作接口。核心创新是让 Agent 像用"爪子"一样在空间中精准定位和操作，而非依赖粗糙的坐标输出。对 GUI Agent 和机器人操作有参考价值。 `HuggingFace` `↑ 85`
- [EvoArena: Tracking Memory Evolution for Robust LLM Agents](https://huggingface.co/papers/2606.13681) — 提出通过追踪 Agent 工作记忆的演化过程来提升多步任务鲁棒性。核心思路：不是给 Agent 更长的上下文，而是帮它更好地管理记忆的增删改查。 `HuggingFace` `↑ 122`
- [WeaveBench: A Long-Horizon, Real-World Benchmark for Computer Use Agents](https://huggingface.co/papers/2606.09426) — 面向 Computer Use Agent 的长时域基准测试，模拟真实世界中的多步骤操作任务。如果你在评估或对比 GUI Agent 方案，这个基准比现有数据集更贴近实际使用场景。 `HuggingFace` `↑ 96`
- [InterleaveThinker: Reinforcing Agentic Interleaved Generation](https://huggingface.co/papers/2606.13679) — 用 RL 训练 Agent 在"思考-行动-观察-再思考"的交替模式中做出更优决策。解决的是 Agent 执行循环中"什么时候该想、什么时候该做"的元决策问题。 `HuggingFace` `↑ 76`
- [MaxProof: Scaling Mathematical Proof with Generative-Verifier](https://huggingface.co/papers/2606.13473) — 将生成式证明与验证器结合，扩展数学定理自动证明的规模。验证器负责筛选可靠步骤，生成器负责探索可能路径，形成闭环。 `HuggingFace` `↑ 76`
- [Robust-U1: Can MLLMs Self-Recover Corrupted Visual Content?](https://huggingface.co/papers/2606.08063) — 研究多模态大模型在视觉输入受损（噪声、遮挡、模糊）时的自我恢复和纠错能力，对提升视觉 Agent 的鲁棒性有参考价值。 `HuggingFace` `↑ 74`
- [FORT-Searcher: Synthesizing Shortcut-Resistant Search Tasks](https://huggingface.co/papers/2606.12087) — 合成对抗"快捷方式依赖"的搜索任务，用于评估 LLM 是否真正理解了搜索目标而非靠表层模式匹配。对关心 LLM 评估质量的读者有启发。 `HuggingFace` `↑ 71`
