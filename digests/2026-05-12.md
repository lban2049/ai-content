## 研究 (Research)

- [BaLoRA: Bayesian Low-Rank Adaptation — 加入贝叶斯不确定性估计的 LoRA 扩展](https://arxiv.org/abs/2605.08110) — 中文摘要：在 LoRA 矩阵上引入输入自适应贝叶斯参数化，在保留低计算开销的同时增加不确定性量化能力；在 LLM 和视觉任务上不仅得到校准的 uncertainty estimate，还提升了预测精度——意味着 adaptive noise injection 本身就是一种有效的正则化手段。 `arXiv` `cs.LG/cs.AI`
- [C-DSAC: Cramér Distance Distributional RL — 用分布视角重构 Soft Actor-Critic](https://arxiv.org/abs/2605.08104) — 中文摘要：将 SAC 置于分布式强化学习框架下，用 Cramér distance 替代均方误差来学习 value 分布，在复杂环境上超越 baseline SAC，且高方差 target 时更新更保守（避免 overestimation），是 RL 算法理论上的细粒度改进。 `arXiv` `cs.LG`
- [TTCD: Transformer 因果发现 — 非平稳时序数据的端到端因果图学习](https://arxiv.org/abs/2605.08111) — 中文摘要：提出 TTCD 框架，用 transformer 编码 temporal + frequency attention 和动态非平稳 profile，再通过 reconstruction-guided causal signal distillation 过滤噪声，在合成、基准和真实数据集（气候/流行病/金融）上均超越 SOTA，因果图推断精度更高。 `arXiv` `cs.LG/cs.AI`
- [Soohak: 数学家策展的 LLM 评测基准 — 超越 MMLU 的数学推理测试](https://arxiv.org/abs/2605.09063) — 中文摘要：由数学家参与的策展数据集，专注于评估 LLM 的真正数学推理能力（非统计模式匹配），在 HF 社区获 39 upvotes，是当前最严格的开源数学评测之一，适合检验模型是否"真正理解"数学而非背答案。 `HuggingFace` `↑ 39`
- [Qwen-Image-2.0 Technical Report — 阿里开源多模态图像模型](https://arxiv.org/abs/2605.10730) — 中文摘要：Qwen 团队发布的新一代图像理解模型技术报告，在多个视觉基准上验证，HF 社区 19 upvotes，反映开源多模态模型竞争仍在快速迭代。 `HuggingFace` `↑ 19`
- [X-OmniClaw: 统一移动 Agent — 一个模型操控手机所有应用](https://arxiv.org/abs/2605.05765) — 中文摘要：面向移动端 UI 操控的统一 Agent 方案，用单个模型同时处理视觉理解 + 操作规划，在多个手机应用评测集上验证，展示了端到端 mobile agent 的可行性。 `HuggingFace` `↑ 15`
- [MatryoshkaLoRA: 分层低秩适配 — 层级化权重分配的新 LoRA 变体](https://arxiv.org/abs/2605.07850) — 中文摘要：在 LoRA 的低秩矩阵上引入分层结构，使不同层的适配能力可按任务需求分配，实验表明在保持计算效率的同时提升了多任务适应能力。 `HuggingFace` `↑ 15`
