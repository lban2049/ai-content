## 研究 (Research)

- [APPO: Agentic Procedural Policy Optimization](https://arxiv.org/abs/2606.12384) — 提出一种新的 RL 训练方法，让 AI agent 能以程序化方式学习策略。与传统的 PPO 相比，APPO 将 agent 的行为序列表示为可执行程序而非数值向量，提高了策略的可解释性和可迁移性。 `HuggingFace Papers` `↑60`
- [Memory is Reconstructed, Not Retrieved: Graph Memory for LLM Agents](https://arxiv.org/abs/2606.06036) — 提出基于图结构的 LLM agent 记忆模型，核心观点是 agent 不应像数据库一样"检索"记忆，而应像人一样"重建"记忆。实验表明图记忆在长对话和复杂任务中优于向量检索方案。 `HuggingFace Papers` `↑53`
- [From Chatbot to Digital Colleague: The Paradigm Shift Toward Agentic AI in the Workplace](https://arxiv.org/abs/2606.14502) — 系统性分析了 AI 从"聊天工具"到"数字同事"的范式转变，梳理了当前企业级 agent 部署的核心挑战（权限、责任归属、人机协作协议）。 `HuggingFace Papers` `↑41`
- [Orchestra-o1: Omnimodal Agent Orchestration](https://arxiv.org/abs/2606.13707) — 提出一个统一框架用于编排多模态 agent 协作，支持视觉、语言、代码等多种模态的 agent 在同一任务中协同工作。 `HuggingFace Papers` `↑36`
- [HarnessX: A Composable, Adaptive, and Evolvable Agent Harness](https://arxiv.org/abs/2606.14249) — 可组合的自适应 agent 框架，支持 agent 在运行时动态加载新能力和工具，不需要重启或重新配置。 `HuggingFace Papers` `↑33`
- [Rethinking RAG in Long Videos: What to Retrieve and How to Retrieve](https://arxiv.org/abs/2606.13141) — 提出针对长视频的 RAG 优化方案，关键发现在于"检索什么"比"怎么检索"对最终效果影响更大。 `HuggingFace Papers` `↑31`
- [From AGI to ASI](https://arxiv.org/abs/2606.12683) — 一篇关于从通用人工智能到超级智能的过渡路径分析，讨论了能力跃迁的可能触发条件和安全挑战。属于观点性论文，适合对 AI 安全长期议题感兴趣的读者。 `HuggingFace Papers` `↑22`
- [WorkBench Revisited: Workplace Agents Two Years On](https://arxiv.org/abs/2606.09817) — 对两年前提出的 workplace agent 基准进行重新评估，发现 agent 在真实办公场景中的表现提升主要来自更好的工具集成而非更强的推理能力。 `arXiv RSS`
