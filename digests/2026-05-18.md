## 研究 (Research)

- [H-Mem: 基于混合结构的 Agent 动态记忆机制](https://arxiv.org/abs/2605.15701) — 提出 LLM Agent 记忆数据的演化建模与高效检索原则，设计了混合结构记忆机制，能随时间动态更新并保持检索效率，对构建长期运行 Agent 有直接参考价值。 `arXiv cs.CL` `new`
- [SMMBench: 多模态 Agent 跨源记忆基准](https://arxiv.org/abs/2605.15710) — 首个评估多模态 Agent 在跨独立来源证据中组合记忆能力的 benchmark，指出当前系统在源分布式记忆场景下的关键瓶颈，对多模态 Agent 评估有指导意义。 `arXiv cs.CL` `new`
- [DimMem: 长程 Agent 记忆的维度化结构压缩](https://arxiv.org/abs/2605.15759) — 解决 Agent 记忆系统中保真度与效率的权衡问题，提出轻量级维度化结构，在保持精确召回的同时显著降低记忆存储成本。 `arXiv cs.CL` `new`
- [Look Before You Leap: LLM Agent 自主探索能力](https://arxiv.org/abs/2605.16143) — 发现 LLM Agent 在陌生环境中因"过早利用"（用先验知识替代信息收集）而失败，提出自主探索作为关键能力的量化评估框架。 `arXiv cs.CL` `cross`
- [FORGE: 无梯度更新的自演化 Agent 记忆](https://arxiv.org/abs/2605.16233) — 通过群体广播协议让 LLM Agent 自我生成记忆实现决策改进，无需权重更新即可持续优化，为构建轻量级自演化系统提供新路径。 `arXiv cs.CL` `new`
- [Measuring Maximum Activations in Open LLMs](https://arxiv.org/abs/2605.16000) — 系统性测量开源大语言模型中的最大激活模式，揭示不同模型架构在特征提取层面的差异，为模型选择和能力评估提供新依据。 `arXiv cs.CL` `new`
- [Calibrating LLMs with Semantic-level Reward](https://arxiv.org/abs/2605.15777) — 提出在语义层级而非词汇层级构建奖励信号来校准 LLM 输出，提升模型对复杂语义判断的准确性，为 RLHF 提供更精细的信号来源。 `arXiv cs.CL` `new`
